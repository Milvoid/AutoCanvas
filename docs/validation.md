## ASR 内存优化验证范围（2026-10-28）

- PyTorch 默认 `asr_dtype = "auto"`，保留检查点精度；支持显式选择 float32、float16 或 bfloat16。
- 模型在独立 spawn 子进程中执行，避免模型和原生分配长期保留在 HTTP 服务内。默认空闲 120 秒退出，后续非静音请求重新加载。
- 工作进程测试覆盖复用、退出回收、崩溃与模型异常恢复、超时清理、静音不加载、空闲重启，以及关闭时结清执行中和排队请求。
- MLX 测试覆盖离线模型解析、会话复用、音频和时间范围保持、量化内存指标与后端派发；轻量模块导入不加载 Torch 或 MLX。
- `/health` 的 ASR 指标提供工作进程与分配器统计；这些指标不等同于操作系统的完整进程内存占用。

公开测试不包含真实课程音频、转写或个人机器的测量原始数据。不同设备、模型、量化配置和音频可能得到不同的内存、速度与识别结果；自动测试不代替真实模型准确率与长期稳定性验证。
