## 真实整节回放处理

- 随后并行执行整节回放 ASR 与 Slides。完整 ASR 验证使用可配置的 15 秒音频块；服务默认仍为 3 秒。
- ASR 使用本地 Qwen3-ASR-0.6B、MPS，处理 2984.768 秒音频，生成 199 个时间片段，执行 succeeded，尝试次数 1。
- Slides 每 5 秒采样，生成 39 张代表画面及联系表，覆盖到 2980 秒，执行 succeeded，尝试次数 1。
- 已查看完整联系表，实际选中屏幕内容。继承 V1 的判定策略，因此个别动画过渡、桌面及结束黑屏可能被保留；未宣称只保留干净 PPT 页面。
- 整节结果位于个人 runtime 的 outputs/<course_id>/<lecture_id> 下；缓存采样画面已清理。

ASR 产物存在并具有完整时间覆盖；本轮没有人工逐句标注，因此不提供识别准确率承诺。
